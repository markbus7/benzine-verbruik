Logboek

    Synchroniseren met GitHub

    Niet gekoppeld

    Met een token bewaart het Tankboek je tankbeurten in een eigen repository, in het bestand data/tankbeurten.json. Zo zie je op je telefoon en je computer dezelfde gegevens. Gebruik hiervoor een privé-repository. In een openbare repository kan iedereen dit bestand lezen.

    1. Maak een lege, privé repository aan, bijvoorbeeld benzine-gegevens.
    2. Maak op github.com/settings/personal-access-tokens/new een fine-grained token.
    3. Kies bij Repository access: Only select repositories en alleen die privé-repository.
    4. Zet onder Repository permissions Contents op Read and write.
    5. Plak de token hieronder. Hij blijft alleen in deze browser staan.
